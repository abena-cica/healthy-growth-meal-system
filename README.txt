HEALTHY GROWTH MEAL SYSTEM — VS CODE WEBSITE

1. Extract this folder.
2. Open the folder in VS Code.
3. Make sure the structure is:
   index.html
   style.css
   script.js
   assets/flyer.png
4. Open index.html in your browser.

EASIEST OPTION IN VS CODE:
Install the free "Live Server" extension, then right-click index.html and choose "Open with Live Server".
